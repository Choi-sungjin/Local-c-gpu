# 검증 범위

릴리스 검사 날짜: 2026-10-20.

## 자동 검사

`python3 -m unittest discover -s tests -v`

- 임시 홈(공백이 포함된 경로)에 설치 및 재설치
- 기존 설정 보존, 명령 충돌 차단 및 명시적 백업
- 없는 실행 파일·잘못된 포트·충돌 옵션 거부
- 실제 가상 터미널에서 두 메뉴 표시, 잘못된 입력 재질문, 취소
- CPU/GPU별 주소·모델 및 세션 인자 전달
- 문서 검색 저장·읽기, 숨김/링크 제외, 임베딩 실패 시 이전 인덱스 보존

모델 응답 대신 가짜 실행 파일과 임베딩을 사용하는 항목이 있습니다.
실제 하드웨어 검증과 구분해서 해석해야 합니다.

## 실제 연결 검사

개인 자료 대신 별도 임시 데이터 폴더와 합성 문서를 사용했습니다.
기존 호스트의 업스트림 실행 파일을 재사용했으며, 새 물리 PC의 최초 설치는 아닙니다.

| 항목 | 결과 |
|---|---|
| 배포판 설치 + RAG 의존성 설치 | 임시 홈에서 성공 |
| 생성한 CPU 서비스 실제 시작 | Ollama 0.32.5 응답, CPUQuota 400%, Nice 10 |
| 포트 충돌 | 이미 수신 중인 서버가 있으면 시작 거부 |
| 서비스 파일 검사 | `systemd-analyze --user verify` 종료 코드 0 |
| CPU Qwen 직접 호출 | `OK` 응답, 2토큰, 초기 로딩 포함 약 24.85초 |
| CPU 하드웨어 확인 | Qwen 및 bge-m3의 `size_vram=0` |
| RAG 직접 연결 | MCP로 도구 목록·검색·문서 읽기 호출 성공, 합성 코드와 상대 경로 확인 |
| OpenCode 설정 로딩 | CPU 모델·12434 주소·local-docs 도구 연결 확인 |
| Hermes 데이터 폴더 초기화 | `hermes config check`, 초기화 후 버전 확인 성공 |

Hermes CPU 실제 검색 답변 검사: **통과**. `hermes-cpu -t local-docs -z ...` 실행이
종료 코드 0, 약 190.11초로 완료됐습니다. 저장된 호출 기록에서
`mcp__local_docs__search_documents` 실행과 샘플 문서 결과를 확인했고,
최종 응답은 `COBALT-731 (sample.md)`였습니다. 답변 문자열만 보고 도구 호출을 추정하지 않았습니다.

최종 로컬 자동 검사: **11개 통과**. 별도 읽기 전용 검토에서도 설치·백업·재설치·
설정 보존·포트 재사용 및 충돌 처리에 대한 재현 검사를 통과했습니다.
Hermes 검색 도구를 직접 노출하는 설정 변경은 위 실제 호출로 추가 확인했습니다.

속도는 다른 작업과 자원을 공유하는 호스트에서 측정한 단일 호출 결과로, 성능 보장치가 아닙니다.

## 미확인 범위

- 다른 물리 PC에서의 최초 설치 전체 과정
- 이 배포판의 GPU 모델 추론, REA 전체 작업, 예약 작업 실제 발화
- OpenCode의 최종 코딩 응답과 빌드 수행
- 재부팅·로그아웃 이후 예약 작업 유지
- Windows/macOS, AMD/Intel GPU
- 모든 모델 답변의 정확성·코딩 품질

CPU/GPU 서비스 분리와 메뉴는 하드웨어 사용 경로를 정하는 기능입니다.
작은 로컬 모델의 코딩 능력을 개선하거나 모든 도구 호출을 보장하지 않습니다.
